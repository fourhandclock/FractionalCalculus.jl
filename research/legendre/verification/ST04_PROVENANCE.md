## ST-04 parameters and evidence

The reduction uses `φ(x)=cos(πx/2)` on `(-1,1)`, homogeneous Dirichlet boundary conditions, zero forcing, initial amplitude one, and `σ=(π/2)²`. The fixed parameters are α=.95, β=.05, λ=1, T=.8, and `K(t)=.05+500/(1+exp(-45(t-.3)))`. This coefficient is smooth, strictly positive, and bounded on the stated interval, and β≤α holds. No spatial discretization is needed for the scalar eigenmode diagnostic.

The supplied script is preserved without modification. It computes L1 and interpolation-defined L1-2 for N=128,256,512,1024,2048,4096 with both the printed Eq. (6) and piecewise-linear product integration. The latter is a control already supplied with the investigation, not a new production scheme introduced by this task. The exponential guard clips its argument to ±600; on `[0,.8]` the actual argument is between −22.5 and 13.5, so the guard is inactive.

The residual check samples `k∈{0,1,2,N//4,N//2,N−1}`. It checks the independent original L1/two-sum L1-2 expression, but reuses the script's corresponding memory routine; it is not an independent memory-assembly oracle. It requires finite trajectories and sampled residual <5e-10. The script's final assertions require weighted peaks >2 for N≥1024 in each scheme/quadrature pair. Its wording about all recurrences must be read with the sampled-residual scope. The verifier uses global α/β defaults even though `solve` exposes optional parameters; this checkpoint executes the default fixed parameter set only.

All 24 configurations and the exact source are retained in fresh run evidence. The supplied PDF/source table gives rounded amplitudes, not certified enclosures. The grid contains six resolutions and five doublings; neither wording nor apparent numerical plateaux establishes an all-sufficiently-large-N result. The limiting α=1,β=0 oscillator calculation and discontinuous-switch mechanism lie outside the paper's open parameter range. The source's proposed smoothing/parameter-continuity/convergence steps remain proof obligations, not completed certificates.

## Claim boundaries

Observation 2 is a verified algebraic discrepancy; Observation 8 is a verified quadrature-order discrepancy; ST-03 establishes a contraction-proof gap. ST-04 is a strong numerical counterexample candidate under the stated smooth positive time-dependent coefficient. It is not a rigorous refutation for arbitrarily fine timesteps, and it does not establish instability or the absence of a weaker finite-time bound. The cited independent 2022 analysis remains source-reported related work, not a proof imported for the combined Volterra problem.
